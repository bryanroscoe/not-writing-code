# Labs

Eight hands-on labs that go with the [course](../README.md). None needs a GPU, model downloads, or an API key. A standard subscription plan covers them.

| Lab | Topic | Unit |
| --- | --- | --- |
| [1](lab-01-tokens-and-temperature.md) | Tokens and temperature | 1: How the machine works |
| [2](lab-02-first-agent-session.md) | Your first agent session | 3: Working with agents |
| [3](lab-03-plan-test-build.md) | Plan, test, build (with an optional verifier-loop extension for Unit 4) | 3: Working with agents |
| [4](lab-04-review-ai-code.md) | Reviewing AI-written code | 4: Trusting the output |
| [5](lab-05-prompt-injection.md) | Prompt injection, safely contained | 4: Trusting the output |
| [6](lab-06-your-own-eval.md) | Build your own eval (doubles as the capstone's eval set) | 3: Working with agents, finishing early in Unit 4 |
| [7](lab-07-multi-agent-review.md) | Multi-agent, cross-model review (doubles as the capstone's review) | 4: Trusting the output |
| [8](lab-08-open-source-contribution.md) | An open-source contribution, done respectfully | 5: Practice for the long run, starting in Unit 4 |

Each lab sits in the first unit where its prerequisites are met. Lab 6 builds the eval from module 07, which students read in Unit 2, but it needs the agent skills from Labs 2 and 3, so it waits for Unit 3. Lab 8 starts during Unit 4 because maintainers can take weeks to reply. The [syllabus](../syllabus.md#course-outline) has the full outline.

Working alone, read the safety review in [Lab 5](lab-05-prompt-injection.md) before you start it.
