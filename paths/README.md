# Start here

Pick the path that fits you. Each one says what to read in full, what to skim, and what to skip on a first pass.

| You are | Path | Time |
| --- | --- | --- |
| A student, or new to AI coding tools | [Student path](students.md) | A semester, or about 15 hours self-paced |
| A working engineer | [Engineer path](engineers.md) | About 6–8 hours, plus a two-week practice plan |
| A lead, manager, or AI champion | [Leads path](leads.md) | About 3 hours, plus the [workplace playbook](../workplace/ai-first-playbook.md) |

Everyone should start with [00: Orientation](../modules/00-orientation.md).

The [modules](../modules/README.md) come in five stages: how the machine works (01–04), choosing a model (05–07), working with agents (08–10), trusting the output (11–14), and practice for the long run (15–18). Each path picks from them in the order that suits its audience.
