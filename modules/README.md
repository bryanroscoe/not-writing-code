# Modules

Sixteen modules, in reading order. Every module has the same layers: Foundations (no background assumed), In practice (what working engineers do), and Going deeper (research and open debates), plus exercises and discussion questions. The [learning paths](../paths/README.md) say which layers to read for your background.

| # | Module | What you'll learn |
| --- | --- | --- |
| 00 | [Orientation](00-orientation.md) | What this is, AI-accelerated coding vs vibe coding, six ideas that outlast the hype |
| 01 | [What is an LLM?](01-what-is-an-llm.md) | Tokens, transformers ("Attention Is All You Need"), pretraining, reasoning models, hallucination |
| 02 | [Training, tuning, and self-tuning](02-training-and-tuning.md) | How models are made, fine-tuning open weights with LoRA, distillation, models that update their own weights |
| 03 | [The model landscape](03-model-landscape.md) | The labs, current lineups, where Meta's Muse fits, the best model for each job |
| 04 | [Open weight vs closed weight](04-open-vs-closed-weights.md) | Licenses, running models locally, where open models sit in the chain |
| 05 | [How to tell if a model is good](05-judging-models.md) | Benchmarks and their flaws, benchmark-maxing, productivity studies, building your own eval |
| 06 | [Harnesses, tools, and MCP](06-harnesses-and-tools.md) | Chat vs IDE vs CLI vs cloud agents, MCP, skills, hooks, products like Claude Design |
| 07 | [Context engineering and the buzzwords](07-context-engineering.md) | Prompt → context → harness → loop → graph engineering, and the rise and fall of giant `CLAUDE.md` files |
| 08 | [Agentic workflows](08-agentic-workflows.md) | The workflow that works, Yegge's eight stages, how much autonomy is real today |
| 09 | [Multiple agents](09-multi-agent-systems.md) | Agents building and reviewing together, and what the research says |
| 10 | [AI code review](10-ai-code-review.md) | Review tools, cross-model review, how humans should review AI-written code |
| 11 | [Security and prompt injection](11-security-and-prompt-injection.md) | Why injection is unsolved, the lethal trifecta, real incidents, sandboxing |
| 12 | [Costs](12-costs-subscriptions-and-apis.md) | Subscriptions vs API billing, why agents eat tokens, a worked cost example |
| 13 | [Open-source ecosystem](13-open-source-ecosystem.md) | Open harnesses, inference engines, frameworks, and the AI-slop problem for maintainers |
| 14 | [Keeping up](14-keeping-up.md) | Model ups and downs, which sources to trust, a sustainable routine |
| 15 | [Learning, careers, and responsibility](15-learning-careers-and-responsibility.md) | Learning with AI without losing the skill, careers, privacy, licensing, ethics |
